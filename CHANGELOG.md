# Изменения

Что менялось при подготовке проекта к переносу во внутренний контур и передаче.
История разработки интерфейса до этого момента в репозиторий не переносилась.

## Подготовка к переносу во внутренний контур — 2026-07-29

**E1 — переименование сервера.** `scripts/dev-api-server.ts` → `scripts/api-server.ts`
(`git mv`, история файла сохранена), обновлены все ссылки. **README переписан с нуля** —
был дефолтным шаблоном Vite.

**ИИ-слой переведён на OpenAI-совместимый API** — жёсткая замена, `@anthropic-ai/sdk`
удалён, добавлен `openai@^7`. Вся конвертация на сервере; браузер провайдера не знает.
Учтено: признак раунда с инструментами по наличию вызовов, а не по `finish_reason`;
результаты инструментов отдельными сообщениями `role:'tool'` с принудительной починкой
парности; сборка потоковых `tool_calls` по `index` с тремя вариантами поведения серверов
по имени; снят `cache_control`; игнорируется `reasoning_content` и вырезаются `<think>`;
ошибки размаплены в понятные сообщения с подсказками по переменным; запрос к модели
отменяется при обрыве соединения. Ключ схемы инструментов переименован
`input_schema` → `parameters` (25 определений).

**Docker.** Multi-stage `Dockerfile`: сборка → рантайм только с продакшн-зависимостями.
Один контейнер отдаёт и SPA, и API — отдельный nginx не нужен. Добавлены `/api/health`
для проб живости и раздача статики с фолбэком на `index.html` (пути `/api/` при этом
дают честную 404, а не страницу приложения). `express` и `tsx` перенесены из
`devDependencies` в `dependencies` — иначе `npm ci --omit=dev` в образе не поднял бы
сервер. Образ здесь не собирался (реестр недоступен из среды агента), но рантайм-стадия
воспроизведена вручную: `npm ci --omit=dev` + `scripts/` + `dist/` — сервер стартует,
проба живости, SPA и клиентские роуты отвечают.

**Побочная находка:** папка `scripts/` **никогда не покрывалась `typecheck`** — в
`tsconfig.node.json` был только `vite.config.ts`. Включена со `strict`, вскрылись и
исправлены две типовые ошибки в модуле токенов (логика не менялась).

**Тесты: 114 вместо 4.** Юниты на конвертацию, сборку вызовов, фильтр размышлений,
ошибки; сквозные против поддельного OpenAI-сервера (полный цикл с инструментом,
`finish_reason=stop` при вызовах, параллельные вызовы, оборванный JSON, ретрай
транзиентной 500, оба режима стриминга, проверка тела запроса); разбор протокола
в браузере; проверка формы всех определений инструментов.

⚠️ **Не проверено:** живого vLLM в среде разработки нет — поддельный сервер
воспроизводит документированный формат OpenAI, а не конкретную сборку заказчика.
Первый запуск в контуре начинать с чек-листа в README.

**Промпты вынесены в папку скиллов.** `src/lib/agentPrompts.ts` (614 строк) разобран
на `src/skills/`: по файлу на каждого из 9 агентов (`agents/`), по файлу на каждый
execution-only сценарий (`executors/` — постановка задачи, QBR, CustDev), общие правила
формата и ссылок в `shared.ts`, базовый промпт и каталог специалистов отдельно. Тексты
перенесены механически и сверены со снимком до рефакторинга — **все промпты совпадают
побайтово**. Добавлен `src/skills/README.md` и тест на инварианты: наличие всех девяти
агентов, непустые промпты специалистов, преамбула несёт общие правила, промпт
оркестратора не начинается с волатильной даты (иначе промах prefix caching).

`typecheck` ✅ · `test` 121/121 ✅ · `build` ✅ · `lint` — 16 предсуществующих.
