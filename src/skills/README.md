# Скиллы ассистента

Системные промпты вынесены сюда — один файл на агента или сценарий. Раньше всё
лежало одним модулем на 600+ строк, и правка одного агента означала поиск нужного
куска в общем файле.

```
src/skills/
  index.ts          единственная точка входа — импортировать отсюда
  shared.ts         правила формата, интерактивные ссылки, дата, преамбула специалистов
  base.ts           общая часть промпта: кто ассистент, блоки choices/suggestions,
                    навигация, сохранение в Базу знаний
  orchestrator.ts   каталог специалистов + двухфазные сценарии (CJM, QBR, CustDev)
  agents/           по файлу на агента — то, что подмешивается при выборе чипа
  executors/        промпты специалистов-исполнителей (execution-only)
```

## Разница между `agents/` и `executors/`

**`agents/`** — фокусные промпты доменов. Используются двояко: как система для
специалиста, который переиспользует домен (`analyze_metrics` берёт `agents/metrics.ts`),
и как акцент при ручном выборе чипа агента в интерфейсе.

**`executors/`** — промпты специалистов, у которых своя логика исполнения, отличная
от домена: постановка задачи, генерация QBR-презентации, CustDev-бриф. Все они
**execution-only**: приходит готовое ТЗ, вопросов не задают, сразу выдают результат.
Интерактивный сбор до этого делает оркестратор.

## Как добавить скилл

1. Создать файл в `agents/` или `executors/`, экспортировать константу
   `ИМЯ_SKILL` со строкой промпта.
2. Для агента — добавить запись в `agents/index.ts` (ключ = `key` карточки агента
   в `AGENT_ITEMS`, файл `AIPanelSider.tsx`).
3. Для исполнителя — реэкспортировать из `index.ts` и подключить в
   `src/lib/specialists.ts` (реестр `SPECIALISTS` + определение инструмента).
4. Прогнать `npm run typecheck` и `npm run test`.

## Что важно помнить

- **Промпт оркестратора уходит в модель на каждой реплике.** Тяжёлые спецификации
  форматов держать в скиллах-исполнителях, а не в `orchestrator.ts`.
- **Волатильное — не в начало промпта.** Дата и имя пользователя в начале ломают
  prefix caching сервера инференса: префикс меняется, кэш промахивается на каждом
  запросе.
- **Правила формата легко сломать.** Запреты на markdown-таблицы, эмодзи и требования
  к кликабельным чипам лежат в `shared.ts` и подмешиваются и оркестратору, и
  специалистам. Если специалисту не дать преамбулу, у него потекут эмодзи и
  перестанут работать чипы метрик — так уже было.

Подробное описание работы агентов целиком — `docs/agents.md`.
